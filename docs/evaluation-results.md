# 해치 평가 결과와 보관 범위

평가 도구를 공개 코드로 정리하면서 반복 프로젝트·패키지 복사본·원시 실행 자료를 push에서 제외했다. 원본은 기존 로컬 작업 공간과 커밋에 보존했으며 삭제하거나 이력을 재작성하지 않았다. [재사용 실행기](../evals/harbor/README.md), [증거 위치와 해시](../evals/harbor/evidence-index.json)에서 확인할 수 있다.

설정 완료 결과의 보고 정확성 판정은 기본 11/12·해치 12/12였다. 한 기본 결과의 성공 주장을 trace로 뒷받침하지 못한 것이며, 거짓이라고 확정한 것은 아니다. 이 차이도 같은 이슈의 두 반복에서 재현되지 않았다.

보관된 패치 24개에는 조건을 가린 독립 AI 리뷰 48건과 추가 테스트를 적용했다. Axios의 회귀 테스트 설계만 두 평가자가 두 반복 모두 해치 쪽을 높게 평가했다. 설계·호환성의 일반적 우위는 확인하지 못했다. 보조 재현에서는 기본 Babel 패치의 첫 호출 회귀와 해치 Axios 패치의 ESLint 실패도 확인했다. 참조 정답도 실패한 확장 경계는 주요 검사 통과 수에 합산하지 않았다. 종합 가중 점수나 일반적 우월성으로 발표하지 않는다.

이 결과는 당시 고정 패키지 SHA-256 `9b95c49b873a7f8a44aa9e7f329700ddf9212b61c6aeb7627fd7754410ecb8c5`에 관한 것이다. 현재 clean-core 버전의 효과를 새로 측정한 결과가 아니다. 실제 저장소 코딩은 같은 모델 `openai/gpt-6-astra`, reasoning effort `medium`, 600초 상한을 사용했다. 총 토큰 상한은 없었다. 해치의 시간·토큰 사용량이 더 컸다는 이전 관찰도 품질 점수와 별개다.

## 공개 코드와 로컬 원본

공개 PR은 실행기, 여섯 자체 과제의 canonical 소스, 공통 lockfile 한 벌씩, 실제 과제 생성 도구, 작은 요약과 증거 식별자를 포함한다. 테스트는 임시 합성 fixture로 과거 평가 디렉터리 없이 실행한다.

원시 jobs/traces/judge-packets, 패키지·하네스 snapshot, 과제별 반복 복사본, SWE-bench 정답·채점 payload·wheel, 대형 압축 원본은 push하지 않는다. 당시 원본은 로컬 `swebench-haechi-eval/haechi` 작업 공간의 `codex/swebench-real-eval` 브랜치에 남아 있다. 최종 보관 커밋은 `6af6e3c4be91327a3100bfa3805240eb11b221a8`이다. 이 커밋을 배포 브랜치에 merge하거나 cherry-pick하지 않았다.

실행을 다시 하려면 먼저 `evals/harbor/README.md`의 입력 동결·원본/참조 수정 교정 절차를 따른다. 과거 비교를 재현하려면 로컬 원본의 고정 과제와 패키지까지 사용해야 한다. 작은 과제 집합을 넘는 효과 검증에는 결과를 보기 전에 고정한 새 holdout이 필요하다.
