# Common work and preview validation

This release centralizes mandatory pre-action, implementation, verification and completion obligations in `principles/work-contract.md`. Task skills provide methods and retain compatible commands and delegation contracts. Later requests receive an applicability/evidence reminder; compaction restores the full rules. These are instructions and delivery mechanisms, not a runtime completion lock.

Preview remains usable on its own or as supporting guidance. Disposable interactive previews are served on localhost and checked directly by the main session. The selected design and interaction evidence carry forward into authorized product implementation. The shared UI-design principle applies to preview creation and review.

## Earlier observations and limits

The earlier controlled D/E comparison completed twelve fresh conversations and sixteen turns. Both variants passed six conversations each. Exact packet measurements found a 15.36% size reduction for the matched implementation jobs while preserving required assets. This is a packet-size result, not a general latency, billing or reliability guarantee. Model behavior, caching and host load were not all separately isolated.

The later installed-Codex check observed nine successful requests and five real compactions, including automatic recovery during one user turn. It used the user-authorized `gpt-6-astra` high route after the account rejected the requested Sol model. This establishes the tested Codex lifecycle path and exact injected content; it is not a Claude-host or GUI interaction test and does not guarantee future model compliance.
